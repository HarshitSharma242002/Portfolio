UX Projects (Figma Related) :


Marvel Theme Website Design

Technology Used : Figma

The Marvel Universe Website is a high-impact entertainment platform designed in Figma to highlight the cinematic world of Marvel. The UI combines bold visuals, powerful colors, and dynamic layouts to showcase movies, characters, and news in an engaging way. It features dedicated sections for popular and upcoming films, an extensive character directory, a news hub, and an informative “About Marvel” segment. The design strives to replicate the dramatic and energetic feel of Marvel Studios while maintaining smooth navigation and a scalable component-based structure.

Squid Games Theme Website Design

Technology Used : Figma

This Squid Game themed website is a visually striking design inspired by the atmosphere of the Netflix series. The interface uses dark tones, neon accents, and iconic Squid Game symbols to deliver an immersive user experience. It includes episode listings, trailer pages, detailed cast and character profiles, and a merchandise store section. The layout focuses on suspenseful aesthetics, interactive visuals, and clean navigation, creating a complete digital portal for fans of the series.

Insurance Application Design

Technology Used : Figma

The Insurance Application UI is a clean, user-friendly interface created to simplify policy management and purchase workflows. It includes a comprehensive dashboard, policy comparison module, guided form flows for purchasing new plans, and intuitive search and filter features. The design uses a professional blue-and-white theme, ensuring clarity and trustworthiness across the app. This project emphasizes accessibility, smooth information flow, and practical navigation for users handling multiple insurance needs.
